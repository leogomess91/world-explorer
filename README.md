# World Explorer 🌍

## 📌 Descrição do projeto

World Explorer é uma aplicação web desenvolvida com React que permite explorar países de diferentes partes do mundo.

O usuário pode pesquisar países e visualizar informações como nome, capital, continente, população e bandeira.

Este projeto foi desenvolvido como parte do projeto final do bootcamp de Desenvolvimento Web da TripleTen.

## 🚀 Funcionalidades

- Navegação entre a página inicial e a página de exploração.
- Exibição de países utilizando uma API externa.
- Pesquisa de países pelo nome.
- Exibição inicial de três cartões.
- Botão "Mostrar mais" para carregar cartões adicionais.
- Mensagem quando nenhum país corresponde à pesquisa.
- Indicador de carregamento durante as requisições.
- Tratamento de erros nas requisições à API.
- Layout responsivo para dispositivos móveis, tablets e desktops.

## 🛠️ Tecnologias utilizadas

- JavaScript
- React

## 🌐 API utilizada

A aplicação utiliza a API pública Countries.dev para obter informações sobre os países.

https://countries.dev

## 💻 Como executar o projeto

Clone o repositório e instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm start
```

A aplicação estará disponível em:

http://localhost:3000

Para gerar a versão de produção:

```bash
npm run build
```

## 📱 Responsividade

O projeto foi desenvolvido com layout responsivo, adaptando-se a diferentes resoluções de tela, incluindo dispositivos com largura de 320px.

## 📂 Organização do projeto

- `src/components` — componentes React.
- `src/utils` — funções responsáveis pela comunicação com a API.
- `src/App.js` — configuração principal da aplicação e navegação.
- `src/App.css` — estilos da aplicação.
- `src/index.css` — estilos globais.
